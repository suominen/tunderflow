# Website plan — `https://kimmo.cloud/tunderflow/`

Publish the TUNderflow tracker as a single-page static site, generated by
**Hugo** locally and rsync'd to a personal nginx server (`haig`). The build
infrastructure mirrors the sibling trackers; only the content and a few
config strings differ.

## Architecture

- **Source repo:** `github.com/suominen/tunderflow` (this repo).
- **Generator:** Hugo extended, ≥ 0.146.0. Run locally; nothing built in CI.
- **Source layout:** Hugo project under `site/`; the tracker is a single
  page at `site/content/_index.md`.
- **Theme:** PaperMod, integrated as a Hugo Module (no submodule).
- **Dev environment:** Nix flake (`flake.nix`) provides hugo + go + git +
  resvg + curl/libarchive/zstd. Auto-activates via `.envrc` with direnv.
- **Build:** `make build` → `hugo --minify --gc --cleanDestinationDir`.
- **Publish:** `make dist` → `rsync -avz --delete site/public/` →
  `haig:/tunderflow/`.
- **Web server:** existing nginx vhost on `kimmo.cloud` serves
  `htdocs/tunderflow/` at the URL path `/tunderflow/`.

## Naming — nickname slug (CVE assigned)

The bug carries a name (**TUNderflow**) *and* a CVE (**CVE-2026-81000**)
from the outset — the name is the one the researcher's write-up and PoC
repository use, and the three bugs disclosed alongside it are being
tracked under their nicknames too. Following the sibling precedent —
which runs both ways (ghostlock, januscape, pintheft, cifswitch, and
sctphantom kept nicknames; Dirty Frag was renamed to
`/CVE-2026-43284/`) — the site uses the **nickname** as its slug
everywhere, with the CVE carried in the tracker body, Summary, and title:

- repo: `~/src/tunderflow`, `github.com/suominen/tunderflow`
- Go module path: `github.com/suominen/tunderflow/site`
- URL: `https://kimmo.cloud/tunderflow/`
- systemd units: `tunderflow-tracker-update.{service,timer}`

No redirect is needed; the slug never moves.

## Companion trackers

TUNderflow was disclosed together with three other local-root bugs by
the same researcher — DirtyAH6 (`/dirtyah6/`), PPPoEject
(`/pppoeject/`), and DiagSpill (`/diagspill/`), seeded the same day from
the same template. The four cross-link each other through a *Related*
row in the Summary, a callout under it, and rows in the References
table. Each tracks only its own CVE: the bugs share a disclosure and the
stable point releases that fixed them, nothing else.

## Tracker content

- One kernel bug, **single verdict axis**: the `447c9303942c` fix is the only
  thing that flips a row. (If the bug has a userspace reachability gate that
  ships as its own package, add a second verdict column — the cifswitch
  two-axis model; see ../DESIGN.md.)
- **Patch status** uses a single combined table for upstream and distros
  (`Distribution | Release | Current kernel | First fixed | Fixed since |
  Status`): the upstream kernel is the first `Linux kernel` group, opt-in
  kernels get their own rows, and per-distro `###` headings appear only
  where there is an audience-relevant note. In the browser the
  Distribution column renders as full-width group heading rows, and the
  column header and group headings are sticky.
- Seed every row from sourced facts — no unconfirmed "fixed" claims.
- Social banner: `site/assets/tunderflow-tracker.svg` → `.png` via
  `make banner`.

## Decisions

- **Hosting:** own nginx on `haig`, not GitHub Pages.
- **Canonical source:** `site/content/_index.md`.
- **Automated maintenance:** a user-level systemd timer runs
  `scripts/auto-update`, which merges `origin/main` into a long-lived
  `auto-update` branch in a separate worktree and hands off to headless
  Claude. The agent commits onto `auto-update` only. Merges to `main` are
  manual.

## Risks & gotchas

- **Subpath baseURL** must keep the trailing slash and path component.
- **`.cleanDestinationDir`** wipes `site/public/` before each build.
- **rsync `--delete`** removes server-side files not in the build output.
- **Anchor drift:** Hugo/Goldmark's slugger differs from GitHub's; pin
  brittle headings with `### Heading {#stable-id}` if needed.
